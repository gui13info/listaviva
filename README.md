# ListaViva

ListaViva é uma aplicação web para gerenciamento de listas de compras de supermercado.

O objetivo do projeto é facilitar a criação e a organização dessas listas em um único lugar.

## Stack planejada

- **Frontend:** Angular e TypeScript.
- **Backend:** Java e Spring Boot.
- **Banco de dados:** PostgreSQL.
- **Ambiente de desenvolvimento:** Docker e Docker Compose.

O uso de inteligência artificial é restrito ao apoio ao desenvolvimento do projeto.

## Estrutura futura do monorepo

```text
listaviva/
├── frontend/        # Aplicação Angular
├── backend/         # API Java com Spring Boot
├── database/        # Scripts e migrations do PostgreSQL
├── infrastructure/  # Docker Compose e configurações de infraestrutura
├── docs/            # Requisitos, arquitetura e decisões técnicas
└── .agents/         # Agentes, skills e workflows de desenvolvimento
```

Essa estrutura é planejada. Os diretórios serão adicionados conforme o projeto evoluir.
